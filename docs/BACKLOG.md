スクラムのやり方で、やりたいことを1か所にまとめる（2026-11-18 から。書き方は咲耶フットボールの docs/BACKLOG.md と同じ）。

- **上にあるほど優先が高い**。並べ替えはプロダクトオーナー（なおなお）が決める
- **ふと出たアイデアは、まず一番下に積む**。並べ替えはあとで
- **スプリント**＝その日の作業くらいの短さ。始めるときに上から何個かを選び、終わったら「済み」へ移す（PR番号と日付を書く）
- **見積もり**（ちーちゃん）：S＝1〜2時間・PR 1本／M＝半日・PR 1〜2本／L＝数日・PRを分けて進める
- 遊んだ人・読んだ人からのアイデア（公式LINEなど）も、ここに積む。出どころを「なぜ」の欄に書く
