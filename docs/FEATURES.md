## F1: オフラインで遊べる

### 目的
機内モードや電波の無い場所でも、ゲームを起動して遊べるようにする。

### 可否と難易度
可能。難易度は「中」（演出動画のオフライン再生だけは「難」）。

### しくみ
- Service Worker で、初回にオンラインで開いたときにゲームに必要なファイルを端末に保存し、2回目からはそこから起動する
- 保存するもの:

  | 対象 | 難しさ | メモ |
  |---|---|---|
  | index.html・画像・アイコン・manifest.json | 易 | 各タイトルのファイル |
  | kit（jsDelivr の `sakuya-kit@<版>`）と CNP の画像 | 易 | 別オリジンだが CORS 付きで保存できる |
  | 書体（Google Fonts） | 易〜中 | 保存できなければ代わりの書体になるだけ |
  | 演出動画（mp4） | 難 | iOS Safari は Range リクエストで読むので、保存した動画を 206 で返す作りが要る。1本3〜4MB |

- Service Worker は同じオリジンに置く決まりがあるので、各タイトルに小さな `sw.js` を1つ置き、中身は kit から読み込む（kit の版と一緒に更新できるようにする）
- 更新: オンラインで開いたときに裏で最新を取り、次の起動で切り替える
- 登録: `createKit` の設定1つ（例 `offline: true`）で kit が `sw.js` を登録する

### 制限
- 一度も開いていない端末では、機内モードで起動できない（最初の1回はオンライン）
- iOS の Safari では、しばらく開かないと保存分が消されることがある（目安7日）。ホーム画面に追加していれば消されにくい
- シェア（X への投稿）はオンラインのときだけ

### 進め方（案）
1. 動画以外をオフライン対応にする。動画はオンラインのときだけ流す（流せないときは今の作りでジングルと結果画面に切り替わる）
2. 1作（ジャンプバグ）で機内モードの動作を実機で確認してから、残りのタイトルに広げる
3. 動画のオフライン再生は、必要になったら足す

### 作業
- [x] kit: `sw-core.js`（保存・更新・古い版の kit の掃除。動画と Range は保存しない）と `offline` の設定（0.4.0）
- [x] kit: ランキングのオフライン表示（「オフラインのため、ランキングは表示できません」）
- [x] kit: playtest に「機内モードで開き直して起動・スタートできる」確認を足す
- [x] skill: starter に `sw.js` と `offline: true`
- [x] kit: タグ 0.4.0
- [x] 咲耶スクランブル: 実機確認・反映（SakuyaScramble#69）。オフラインでは演出動画を飛ばし、クリアは静止画と結果画面
- [x] 咲耶ジャンプバグ（SakuyaJumpBug#4）・咲耶Nounラリー（SakuyaRallyCnp#49）・咲耶ディグ（SakuyaDig#11）に反映

## F2: オフラインのスコアを後で送る

### 目的
オフラインで遊んだ記録も、ランキングに載せられるようにする。

### 可否と難易度
可能。難易度は「中」。F1 と組み合わせて使う（F1 が無くても、通信が切れていたときの再送として効く）。

### しくみ
- 登録フォームで送れなかった記録は、端末（localStorage）にためておく
- オンラインに戻ったとき（`online` イベント）と、次にゲームを開いたときに、ためた記録を自動で送る
- ランキング欄は、最後に取れた TOP10 を「オフライン中」と添えて出す
- iOS には閉じたアプリの裏で送る仕組み（Background Sync）が無いので、オンラインで一度ゲームを開いたときに送る

### 決めごと（案）

| 課題 | 案 |
|---|---|
| TOP10 に入ったかの判定 | 最後に取れた TOP10 で判定してフォームを出す。送るときに圏外になっていても、そのまま記録する |
| X ID の確認（unavatar.io） | オフラインでは後回しにし、送る直前に確かめる。見つからなければ X ID を外して送る |
| 二重登録 | 記録ごとに番号（ID）を付け、GAS が同じ番号の記録を断る（GAS の貼り直しが1回要る） |

### 作業
- [ ] 決めごとの確定
- [ ] kit: ランキング部品に送信待ちの列（保存・再送・表示）を足す
- [ ] GAS: 記録の番号で二重登録を断る。スプレッドシートに列を1つ足す
- [ ] 各タイトル: kit の版を上げる
