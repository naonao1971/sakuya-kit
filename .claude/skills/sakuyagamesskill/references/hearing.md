# ヒアリングの質問票と企画書のひな形

上から順に、まだ決まっていないものだけ聞く。1ラウンド4問まで。
（おすすめ）は元ネタと既存3作の作りから選ぶ。利用者が「任せる」と言ったら、おすすめで決めて復唱する。

## ラウンド 1: 遊びの芯

1. **元ネタから借りるもの**（元ネタごとに `retro-catalog.md` の「借りどころ」から2〜3個の選択肢）
2. **1プレイの長さ**: 3分くらい（おすすめ）／1分で終わる短いもの／10分くらいのステージ制
3. **終わり方**: ゴールしたらクリア（おすすめ）／ステージが続くエンドレス／制限時間で終わる
4. **CNP 11体の役割**: 拾って集める（おすすめ）／助け出す／仲間として一緒に戦う／ボーナスとして出る

## ラウンド 2: 操作

1. **スマホの移動**: 左半分のスティック（おすすめ）／canvas のどこでもスティック（迷路向け）／傾き（ジャイロ）
2. **ボタン**: 1つ（おすすめ）／2つ（例: 撃つ＋ボム、ジャンプ＋撃つ）
3. **自動連射**: いる（撃つゲームならおすすめ）／いらない
4. **難しさ**: 最初はやさしく、だんだん難しく（おすすめ）／最初から歯ごたえ

## ラウンド 3: 見た目と名前

1. **日本語名**: 「咲耶〇〇」の形で2〜3案出して選んでもらう
2. **英字の主題と副題**: 例 `SAKUYA SCRAMBLE` / `- RESCUE 11 CNP -`（日本語名から案を出す）
3. **世界観・ステージ**: 和風の城下町／宇宙／洞窟 など、元ネタと咲耶の組み合わせから2〜3案
4. **絵と動画**: キービジュアル（横長）と、クリア／ゲームオーバーの動画を用意するか（後からでもよい）

## ラウンド 4: 公開

1. **公開 URL**: `xxx.naoblock.jp`（既存: sakuya / rally / jumpbug）
2. **リポジトリ名**: 例 `SakuyaXxx`
3. **総合ランキングに入れるか**: 入れる（おすすめ）／入れない
4. **わいわいタウンに載せるか**: 載せる（おすすめ）／あとで

`gameId` は英小文字（例 `scramble` / `rally` / `jumpbug`）で、こちらから案を出して確認だけ取る。あとから変えない。
